Intro
흩어진 북마크를
한눈에 탐색하다
Chrome 북마크를 폴더 기준으로 수집·시각화하고, 검색·정렬·폴더 이동을 제공하는 브라우저 확장 프로그램입니다. 15명 이상의 실제 사용자에게 배포되어 운영 중입니다.
GitHub Chrome Store
Problem
기본 북마크 관리자의
불편한 탐색 흐름
Chrome 기본 북마크 도구는 탐색 흐름이 깊고, 수정·이동·검색 액션이 직관적이지 않았습니다. 저장만 하고 다시 들여다보지 않는 패턴이 반복되었습니다.
Core Feature
개인화된
북마크 관리 경험
폴더 색상 설정, NEW 배지, 드래그 앤 드롭, 다크모드 테마 전환으로 사용자가 자신만의 방식으로 북마크를 정리할 수 있는 경험을 제공합니다.
Technical Challenge
트리 구조 데이터를
UI에 맞게 재설계
Chrome Bookmarks API의 트리 구조 데이터를 폴더와 북마크로 분리해 렌더링하고, 로케일별 분기 처리 오류를 ID 기반으로 해결하며 API 데이터와 UI 상태를 안정적으로 동기화했습니다.
Result
단순 조회를 넘어
개인화 생산성 도구로
단순 저장 기능에서 실제로 탐색하고 정리하는 도구로 확장했습니다. 기존 사용자들이 서비스 공유 후 현재까지 지속적으로 사용하고 있습니다.
